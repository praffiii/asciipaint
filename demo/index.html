asciipaint
GitHub npm

Paint any image, video, canvas or three.js scene as coloured ASCII that reads like a painting.

Live: a canvas animation, painted as glyphs about 30 times a second. Up close it is text.

Install

npm i asciipaint

No bundler? Import it from a CDN:

import { asciipaint } from "https://esm.sh/asciipaint";

three (0.170 or later) is optional, needed only for asciipaint/three.

One tag

Any image as an element. Every element on the page shares one WebGL context.

<script type="module">
  import "asciipaint/element";
</script>
<ascii-img src="/logo.svg" alt="Logo" width="160" height="160"></ascii-img>

Logo wall

Twenty-four <ascii-img> elements, half viewBox-only SVG and half transparent PNG. Browsers allow about 16 live WebGL contexts; these share one.

API

Any image, video or canvas:

import { asciipaint, autoRender } from "asciipaint";

const paint = asciipaint(canvas, { cell: [2.4, 3.4], ramp: "-=+*#%@" });
paint.draw(source); // image | video | canvas | ImageBitmap | VideoFrame
paint.set({ background: "#F4EEDF", sparkle: true, edgeFade: 0.076 }); // live
paint.resize();
paint.dispose();

A loop at about 30 fps that pauses off screen and in a hidden tab, and honours reduced motion: 

const loop = autoRender(paint, () => paint.draw(video), {
  onContextLost: () => showFallback(),
});
loop.requestFrame(); // the only frame source under reduced motion
loop.stop();

A three.js scene, on the renderer's own canvas and context:

import { asciipaintThree } from "asciipaint/three";

const paint = asciipaintThree(renderer, options);
paint.render(scene, camera); // replaces renderer.render(scene, camera)
cell
CSS px per glyph cell, [width, height]. Default [2.4, 3.4].
ramp
Glyphs from dark to bright, 2 or more. Default "-=+*#%@".
font
Any loaded monospace font. Default Geist Mono 600.
background
The paper the art sits on, a CSS colour or [r, g, b] in 0–1. Live.
edgeFade
Dithered dissolve depth as a fraction of the width; 0 is a hard edge. Live.
sparkle
Bright isolated points become * or + with a glow. Live.
dpr
Device pixel ratio, capped at 3. The three.js add-on follows the renderer.
